# 🕷️ Spider Clock

A cinematic, real-time web clock experience built with **Next.js, TypeScript, and Tailwind CSS**.

Spider Clock combines an animated spider-themed clock with global timezones, alarms, stopwatch, timer, and interactive visual themes.

## ✨ Features

* 🕷️ Animated Spider Clock
* 🌍 Global World Clock
* ⏰ Alarm with sound selection and preview
* ⏱️ Stopwatch with lap tracking
* ⏳ Countdown Timer
* 🎨 Multiple visual themes
* 🖥️ Fullscreen mode
* 📱 Fully responsive design
* ⚡ Real-time clock updates
* ⌨️ Keyboard shortcuts
* ✨ Premium glassmorphism UI
* 🌐 Timezone selection
* ♿ Reduced-motion support

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Web Audio API
* Intl DateTimeFormat API

## 🚀 Getting Started

Clone the repository and open the frontend:

```bash
git clone https://github.com/tawhed08/spider-clock.git
cd spider-clock/frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## 🧪 Production Check

Run lint:

```bash
npm run lint
```

Run production build:

```bash
npm run build
```

## ⌨️ Keyboard Shortcuts

### Alarm

* `Space` — Start/Stop alarm
* `Escape` — Dismiss alarm
* `C` — Clear alarm

### Stopwatch

* `Space` — Start/Pause
* `R` — Reset
* `L` — Record lap

### Timer

* `Space` — Start/Pause
* `R` — Reset
